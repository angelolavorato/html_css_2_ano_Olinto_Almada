Bem-vindo ao portal

Esta página foi criada para demonstrar como o Flexbox ajuda a organizar elementos em uma página web. O menu superior, os cards das disciplinas e os exemplos visuais abaixo usam Flexbox para alinhar, distribuir e controlar o espaço entre os elementos.

O que o Flexbox está demonstrando?

O Flexbox funciona a partir de um elemento pai, chamado de contêiner flexível. Quando usamos display: flex nesse contêiner, seus elementos filhos passam a ser organizados em linha ou coluna, podendo ser alinhados, espaçados e distribuídos com mais controle.

Contêiner flexível

É o elemento que recebe display: flex. Nesta página, o menu, a lista de cards e os exemplos visuais são contêineres flexíveis.

Eixo principal

É a direção principal dos itens. Em uma linha, o eixo principal vai da esquerda para a direita. Em uma coluna, vai de cima para baixo.

Alinhamento

Propriedades como justify-content e align-items controlam a posição dos itens dentro do espaço disponível.

Cards organizados com Flexbox

Os cards abaixo estão dentro de um contêiner com display: flex. Por isso eles ficam lado a lado, mantêm espaçamento uniforme e podem quebrar para outra linha em telas menores.
