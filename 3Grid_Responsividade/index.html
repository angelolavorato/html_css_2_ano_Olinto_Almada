Praticando Grid e Responsividade

O que esta página demonstra?

Esta página mostra como o CSS Grid organiza uma interface em linhas e colunas, e como a responsividade adapta esse layout para diferentes tamanhos de tela. Em telas maiores, o conteúdo principal e a lateral ficam lado a lado. Em telas menores, eles passam a ocupar uma única coluna para facilitar a leitura.

Grid

Cria uma grade com colunas e linhas para posicionar elementos com mais controle.

Responsividade

Faz a página se adaptar ao espaço disponível, sem depender de uma única largura fixa.

Media Query

Aplica estilos diferentes quando a tela atinge uma largura específica.

Conteúdos principais

Os cards abaixo formam uma grade interna. No computador, eles aparecem em duas colunas. Em telas pequenas, a media query transforma essa grade em uma coluna só.

Box Model

Entenda como os elementos funcionam como caixas.

Display

Controle como os elementos aparecem na página.

Flexbox

Organize elementos em linha ou coluna.

Grid
